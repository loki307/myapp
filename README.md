# 🎓 Student Record Management System

A full-stack Python Flask web application with CRUD operations, containerized with Docker and deployed on Kubernetes (Minikube).
live site:https://myapp-3op4.onrender.com/

## 🚀 Technologies Used
- **Python** - Backend language
- **Flask** - Web framework
- **HTML/CSS** - Frontend UI
- **Docker** - Containerization
- **Kubernetes (Minikube)** - Container orchestration
- **GitHub** - Version control
- **GitHub Actions** - CI/CD Pipeline

## 📋 Prerequisites
- Docker Desktop
- Minikube
- kubectl
- Python 3.9+
- Git
- 
## 🌟 Features
- Full CRUD operations (Create, Read, Update, Delete) on student records
- Clean, responsive dark-themed UI
- REST API endpoints (JSON) for testing and integration
- Dockerized Python Flask application
- Kubernetes deployment with 2 replicas for high availability
- Automated CI/CD pipeline with GitHub Actions

## 🔗 API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /students | Get all students |
| GET | /students/\<id\> | Get a single student |
| POST | /students | Add a new student (JSON) |
| PUT | /students/\<id\> | Update a student (JSON) |
| DELETE | /students/\<id\> | Delete a student |
